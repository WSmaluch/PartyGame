# PartyGame 1.0.0-rc.1 — Release Candidate

RC1 packages the completed automated release readiness work: durable media storage, data lifecycle controls, LAN deployment, security hardening, diagnostics and the deterministic Mixed Client E2E flow. The supported game questions are PlayerSelection, TextAnswer, PhotoAnswer and DrawingAnswer.

The distribution archive installs without an IDE or source checkout. It includes API, Display, Admin, lifecycle commands, backup/restore, diagnostics and support-bundle tooling. The package uses SHA-256 checksums; its runtime lives outside the immutable release directory. A private-LAN HTTP install requires explicit host selection and uses an operator bearer token; use HTTPS when the boundary is not a trusted LAN.

Known limitation: automated validation does not replace physical-device acceptance. Test an iPhone, second computer/tablet and TV/Display with the checklist before declaring final production readiness. Do not publish `v1.0.0` until that acceptance is recorded.
