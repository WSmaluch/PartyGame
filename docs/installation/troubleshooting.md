# TROUBLESHOOTING

Run `scripts/status.sh`, `scripts/diagnose.sh` and `scripts/diagnose-lan.sh` first. Confirm the host is a private IPv4 address, port 5050 is free, firewall access is allowed and iOS uses the LAN host rather than `localhost`. Attach the version, commit and redacted support bundle to a report; do not attach tokens, databases or raw media.
